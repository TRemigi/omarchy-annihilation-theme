Tried and dropped: fibres fanning from each neck cut through the icons like scratches. Not included: bulbs that overhang the edge on a narrow neck. Pits failed the first time because the interior was too dark for them to show; the inner glow is what makes them work.

Where this leaves the build

  • The bloom and spill extend about 25px outside each section, so the bar's window needs transparent margin around the strip. It already spans the screen, so the reserved width doesn't change.
  • The globs change the outline itself, so each section becomes a polygon of about 1,500 points instead of a few curves. That is fine to draw, but it has to be regenerated whenever a section resizes, and the globs need the same fixed seed as the pits. The pits, and the cluster behind the active workspace, are scattered from a fixed seed, so they stay put when widgets come and go. The real version would need that too, or they'd shimmer on every resize.
  • The uneven rim light is a fixed gradient here. It could drift slowly along the rim, tied to the Shimmer's speed, so the bar breathes with the rest of the theme.
  • I haven't measured the cost of the blurs in Quickshell, and I can't run it here. If they're heavy, the bloom can be pre-rendered per section size.

Still open

  • Which layers stay. Calm is the lit rim, spill and inner glow; Full adds the edge globs, pits, nucleus and shimmer core.
  • States I haven't drawn: hover on a widget, an alert (the missed-notification mark), and a hidden or auto-peeking bar.
  • Motion: whether the neck pinches when you change workspace.
